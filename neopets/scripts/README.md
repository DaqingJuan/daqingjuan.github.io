# 尼奧腳本工具箱

Neopets 用的 Tampermonkey 腳本。完整說明和安裝按鈕在下載頁：
https://daqingjuan.github.io/neopets/scripts/

## 自己做的（放在這個資料夾）

| 腳本 | 用途 | 安裝 |
|---|---|---|
| NPC 商店行情標籤 | NPC 商店、拍賣場、交易站等頁面，在物品圖片左上角顯示 itemdb 市價 | [npc-price-tag.user.js](https://daqingjuan.github.io/neopets/scripts/npc-price-tag.user.js) |
| A Piece of Neopia 拼圖小幫手 | 週年慶滑塊拼圖自動解（3×3～5×5） | [puzzle-helper.user.js](https://daqingjuan.github.io/neopets/scripts/puzzle-helper.user.js) |
| 黑帕奇拉霸自動玩 | Black Pawkeet Slots 自動轉（機器人行為，有凍結風險） | [pawkeet-slots-autoplay.user.js](https://daqingjuan.github.io/neopets/scripts/pawkeet-slots-autoplay.user.js) |
